GitHub sync

Each saved trade, with a snapshot of your checklist at that moment, is committed to a JSON file in your private data repo. These settings stay on this device.

Use a fine-grained token limited to your data repo only, with Contents set to read and write. Trades that fail to sync stay marked Pending and retry on the next save or page load. Deleting a trade here does not remove it from GitHub.
